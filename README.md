# Daspro Jobsheet 5 — Struktur Pemilihan (If-Else)

Program latihan **struktur pemilihan** pada Java: percabangan `if`,
`if-else`, dan `if-else` bersarang untuk kasus-kasus sehari-hari.

## Daftar Program

| Program | Deskripsi |
|---------|-----------|
| `Umur.java` | Validasi usia dengan `if-else` |
| `PemilihanHari13.java` | Menentukan hari dari input angka |
| `PemilihanHariDenganif.java` | Versi percabangan `if` |
| `PemilihanBilangan13.java` | Klasifikasi bilangan (positif/negatif/nol) |
| `Kafe.java` | Studi kasus pemesanan kafe |
| `Siakad13.java` | Studi kasus penentuan status SIAKAD |

## Cara Menjalankan

```bash
javac Umur.java
java Umur
```

## Konteks

Jobsheet 5 Dasar Pemrograman, Politeknik Negeri Malang (Polinema).
